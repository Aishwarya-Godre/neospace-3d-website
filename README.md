# ✦ NEOSPACE — 3D Space Exploration Website

### 🚀 Explore the Unknown. Discover the Extraordinary.

NEOSPACE is a futuristic, interactive 3D space exploration website designed to deliver an immersive visual experience. It combines modern web design, animated space visuals, and interactive 3D graphics to create a beautiful digital universe.

## ✨ Features

- 🪐 **Interactive 3D Planet** — A rotating 3D sphere rendered using Three.js.
- 🌠 **Animated Starfield** — A space-inspired background with moving stars.
- 💜 **Futuristic UI** — Dark theme with glowing purple and cyan accents.
- 🖱️ **Mouse Interaction** — Planet movement responds to pointer movement.
- 📱 **Responsive Design** — Adapts to desktop, tablet, and mobile screens.
- 🎨 **Modern Visual Effects** — Gradient text, orbital rings, and glowing elements.
- 🧭 **Smooth Navigation** — Navigate between Home, Explore, and About sections.

## ⚙️ How to Run Locally

**Step 1:** Clone the repository.

```bash
git clone https://github.com/YOUR-USERNAME/neospace-3d-website.git
```

**Step 2:** Open the project folder.

```bash
cd neospace-3d-website
```

**Step 3:** Open the folder in Visual Studio Code.

**Step 4:** Install the Live Server extension.

**Step 5:** Right-click `index.html` and select **Open with Live Server**.

The website will open in your browser.

> An internet connection is required to load the Three.js library from its CDN.
